## The licence this project relies on

The pinned release was downloaded from `https://marks.hms.harvard.edu/proteingym/ProteinGym_v1.3`, which states no licence. The same release is deposited at [10.5281/zenodo.15293562](https://zenodo.org/records/15293562) under **mit-license**, and the assay archive's digest there is identical to the pinned copy, so the deposit's grant is the grant on the bytes this project read.

- MIT is a software licence. Applying it to a data deposit is ordinary practice on Zenodo and it is the maintainers' own stated choice, but its effect on data is less settled than on code. Recorded as the grant relied on, not as a legal conclusion
- the deposit's grant is the maintainers'. It does not reach back and relicense the studies that produced the assays, which is why each study's own terms are carried per assay below

## What is published here, and what is not

Published:
- assay identifiers, organism and taxonomy, family and order, and the arm each assay falls in under each reading of each filter policy
- per-assay counts: variants and sequence length, as the pinned release states them
- the DOI of the study that produced each assay
- scores this project computed, per variant and per assay, and the rank correlations derived from them

Not published:
- the measured fitness values themselves — the assay data stays in the pinned release and is read from it, never re-hosted here
- the benchmark's own published model scores, which are read from the pinned release for the reference check and reported only as an agreement statistic

## How to cite

1. the collection: Notin et al., ProteinGym, Advances in Neural Information Processing Systems 36 (2023)
2. the pinned release as data: 10.5281/zenodo.15293562 (ProteinGym v1.3, https://zenodo.org/records/15293562)
3. the study that produced the assay, by the DOI carried on its entry below

Citing only the collection drops the groups whose experiments the analysis rests on, and citing only the studies loses the pinned release a result regenerates from.
